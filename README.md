# Dashboard di Mattia

Un dashboard personale pensato per raccogliere in un unico spazio le principali aree della vita quotidiana:

- **Lavoro**: registrare le attività lavorative, le ore e la paga attesa.
- **Università**: tenere sotto controllo gli esami e le informazioni legate allo studio.
- **Sport**: seguire le attività di corsa e i progressi settimanali.
- **Casa**: organizzare le attività e le responsabilità domestiche.

## Descrizione del progetto

L'obiettivo del progetto è creare uno spazio unico e pratico per visualizzare i propri impegni, i riepiloghi e le attività in programma. Il dashboard riunisce in una sola interfaccia le informazioni relative a lavoro, università, sport e casa, così da rendere più semplice avere una visione generale della giornata e delle prossime attività.

La pagina **lavoro** è attualmente l'unica area completamente funzionante. Le altre sezioni fanno parte della direzione prevista per il progetto e possono ancora contenere dati di esempio o funzionalità incomplete.
